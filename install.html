Jarin Навигатор — бесплатный GPS-навигатор

Jarin (Жарин) — бесплатный голосовой навигатор для Android и iPhone. Приложение строит маршруты по реальным дорогам, учитывает пробки, озвучивает повороты голосом друга «Лоада»: «поверните направо», «поверните налево». В навигаторе есть поиск адресов и организаций, избранные места, отчёт за смену и светлая/тёмная темы.

Как установить:

  • Android — скачайте APK кнопкой выше и откройте файл. При запросе разрешите установку из неизвестных источников.
  • iPhone (iOS) — откройте сайт в Safari, нажмите «Поделиться» и выберите «На экран „Домой"». Jarin откроется как обычное приложение.
  • Компьютер — откройте сайт в любом браузере, приложение работает онлайн.

Jarin Навигатор — полностью бесплатный, без рекламы и регистрации. Не тратит интернет-трафик впустую: карты подгружаются только там, где вы едете.
